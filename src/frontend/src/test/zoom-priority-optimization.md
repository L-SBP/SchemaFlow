# 缩放优先级优化 - 左侧全局侧边栏优先收起

## 优化目标

确保在放大过程中，最左侧的全局侧边栏（数据库面板）最先自动收起，而且不与手动收起展开冲突。

## 优化前的问题

### 原有优先级（有问题）
1. **缩放 >200%**: 右侧会话栏先收起
2. **缩放 >300%**: 左侧数据库侧边栏再收起

### 问题分析
- 左侧数据库面板是全局侧边栏，应该优先收起以释放更多空间
- 右侧会话栏相对较窄，对空间的影响较小
- 用户更关注对话区域，应该优先保证对话区的可用空间

## 优化后的解决方案

### 新的优先级（已优化）
1. **缩放 >200%**: 左侧数据库侧边栏（全局侧边栏）**最先**自动收起
2. **缩放 >250%**: 右侧会话栏再收起
3. **对话区**: 始终保持可见（最后保留）

### 关键改进点

#### 1. 调整收起顺序
```javascript
// 优化前（有问题）
if (zoomLevel > 200) {
  // 先收起右侧会话栏
  if (isRightPanelOpen) {
    setIsRightPanelOpen(false);
  }
  // 缩放 >300% 才收起左侧面板
  if (zoomLevel > 300 && isLeftPanelOpen) {
    setIsLeftPanelOpen(false);
  }
}

// 优化后（正确）
if (zoomLevel > 200) {
  // 首先收起左侧数据库侧边栏（全局侧边栏）- 最先自动收起
  if (isLeftPanelOpen && !userManuallyClosedLeft) {
    setIsLeftPanelOpen(false);
  }
  // 缩放 >250% 才收起右侧会话栏
  if (zoomLevel > 250 && isRightPanelOpen && !userManuallyClosedRight) {
    setIsRightPanelOpen(false);
  }
}
```

#### 2. 尊重用户手动操作
```javascript
// 只有在用户没有手动关闭的情况下才自动收起
if (isLeftPanelOpen && !userManuallyClosedLeft) {
  setIsLeftPanelOpen(false);
}
```

#### 3. 优化恢复逻辑
```javascript
// 缩放级别降低时按正确顺序恢复
if (zoomLevel <= 200 && is.desktop) {
  // 优先恢复左侧数据库面板（全局侧边栏）
  if (!isLeftPanelOpen && !userManuallyClosedLeft && viewportWidth >= 1200) {
    setIsLeftPanelOpen(true);
  }
  // 然后恢复右侧会话面板
  if (!isRightPanelOpen && !userManuallyClosedRight && viewportWidth >= 1440) {
    setIsRightPanelOpen(true);
  }
} else if (zoomLevel <= 250 && zoomLevel > 200) {
  // 中等缩放级别时，可以恢复左侧面板，但保持右侧面板收起
  if (!isLeftPanelOpen && !userManuallyClosedLeft && viewportWidth >= 1200) {
    setIsLeftPanelOpen(true);
  }
}
```
